## 0.1 一键启动（2026-10-31）

项目根目录已提供双击即用的启动器，**不用再手敲 uvicorn / npm**：

| 文件 | 作用 |
|------|------|
| `start.bat` | 入口（ASCII，双击即用），转发参数给 `start.ps1` |
| `start.ps1` | 环境检查 → 起后端(8000)/前端(5173) → 轮询就绪 → 弹浏览器 |
| `stop.bat` / `stop.ps1` | 按端口 + 命令行定位，结束本项目的 python / node 进程 |

参数：`-Restart`（先停再起）、`-NoBrowser`（不弹浏览器）、`-NoPause`（不等待按键）。
端口已占用时自动复用，重复双击不会产生多套服务。
