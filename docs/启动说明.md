# 启动说明

## 最快的方式：双击 `start.bat`

在项目根目录双击 **`start.bat`**，脚本会自动：

1. 检查 Python / Node 与前端依赖（首次缺依赖会自动 `npm install`）
2. 在**同一个窗口**里启动后端（:8000）与前端（:5173），日志以 `[后端]` / `[前端]` 前缀实时汇总
3. 轮询 `/api/health` 与前端地址，**真正就绪后**才继续（不是傻等固定秒数）
4. 自动打开浏览器到 http://localhost:5173

按 `Ctrl+C` 会同时停掉前后端（不会再留下孤儿进程）。

细节：

| 情况 | 行为 |
|------|------|
| 端口已被占用 | 跳过启动、直接复用（第二次双击不会重复开服务） |
| 双击 `stop.bat` | 按端口 + 命令行定位并结束本项目的 python / node 进程 |
| `start.bat -Restart` | 先结束本项目服务再重新启动 |
| `start.bat -NoBrowser` | 只起服务、不弹浏览器 |
| 前端端口 | 用 `--strictPort` 锁死 5173，避免 vite 自动跳 5174 导致开错地址 |

脚本文件：`start.bat`（入口，ASCII，双击即用）/ `start.ps1`（主逻辑）/ `stop.bat` / `stop.ps1`。

### 想要桌面图标？

`start.bat` 是批处理文件，Windows 只能给它一个通用齿轮图标。要显示 WordCut 自己的图标，运行一次：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\make_shortcut.ps1
```

它会在桌面创建「WordCut 词剪」快捷方式，指向 `start.bat` 并套用 `assets\wordcut.ico`。
（控制台窗口本身的图标由 Windows 控制台宿主决定，快捷方式影响的是桌面 / 开始菜单 / 任务栏固定后的图标。）

## 依赖与模型：全部可以自动下载

仓库**不含模型**（`small` 约 460MB）。第一次点「转写」时，如果
`models/faster-whisper-small/` 不存在，后端会自动从 HuggingFace 拉取，
官方源不通就自动换国内镜像 `hf-mirror.com` 重试，落到
`models/faster-whisper-<名字>/`，之后直接复用。下载进度会打在启动窗口的
`[后端]` 日志里。

想提前预热（推荐首次安装后跑一次，它还会顺带检查 ffmpeg / CUDA / Python 依赖）：

```powershell
python scripts\ensure_models.py                 # 检查 + 下载默认模型
python scripts\ensure_models.py --model medium  # 换模型尺寸
python scripts\ensure_models.py --no-download   # 只体检，不联网
```

离线环境：

```powershell
set WORDCUT_NO_MODEL_DOWNLOAD=1
set WORDCUT_WHISPER_MODEL_PATH=D:\models\faster-whisper-small
```

| 环境变量 | 默认 | 作用 |
|----------|------|------|
| `WORDCUT_WHISPER_MODEL` | `small` | 模型尺寸（tiny/base/small/medium/large-v3） |
| `WORDCUT_WHISPER_MODEL_PATH` | 空 | 指定已有模型目录，优先于下载 |
| `WORDCUT_MODELS_DIR` | `<项目>\models` | 模型根目录 |
| `WORDCUT_NO_MODEL_DOWNLOAD` | 空 | `1` = 禁止自动下载 |
| `WORDCUT_WHISPER_DEVICE` | `auto` | `auto`/`cuda`/`cpu`（做 CPU-GPU 对照实验用） |
| `WORDCUT_WHISPER_BATCHED` | `1` | `0` = 关闭批处理转写 |

## 前置

- Python 3.10 + 依赖：fastapi uvicorn faster-whisper ctranslate2==4.4.0 numpy soundfile
- Node.js 20+
- 模型：`E:\WordCut\models\faster-whisper-small`（config.json / model.bin / tokenizer.json / vocabulary.txt）

> ⚠️ ctranslate2 必须是 **4.4.0**（4.8.3 在本机 CPU/GPU 均崩溃 0xC0000005）

### GPU 加速（已启用）

转写默认 **auto**：先探测 CUDA，可用就用 GPU（float16），否则退回 CPU（int8）。

- 自检：`python scripts/check_cuda.py`（直接告诉你缺什么）
- 环境变量：
  - `WORDCUT_WHISPER_DEVICE=auto|cuda|cpu`（默认 auto）
  - `WORDCUT_WHISPER_COMPUTE=float16|int8_float16|int8`（默认按设备）
- ctranslate2 4.4.0 需要 **CUDA 12 + cuDNN 8**：缺 `cudnn_ops_infer64_8.dll` 时
  GPU 加载会**硬崩**（不是抛异常），所以探测放在独立子进程里，崩了不影响后端。
- 模型加载后 `/api/health` 会显示 `whisper_device` / `whisper_compute_type` / `whisper_note`。

**本机运行库放在 `E:\WordCut\libs\cuda\bin`**（约 1.7GB，未入版本库）：

```powershell
# 需要重装时（走 Clash 代理 7890）
python scripts/fetch_cuda_libs.py
python scripts/check_cuda.py     # 看到「CUDA 可用: 是」即可
```

- 内容：cuDNN 8.9.7.29（CUDA 12）+ cuBLAS 12.9.2.10 的 Windows DLL
- `api.py` 在加载模型前会把该目录注册进 `os.add_dll_directory` 与 `PATH`，
  两种安装方式（本项目自带 / pip 的 `nvidia-*` 包）都能被找到
- 实测（180.5s 素材，RTX 4050 Laptop / i7）：GPU **10.5s** vs CPU **48.6s**，**4.6×**

```powershell

```

> 注意：vite 只监听 IPv6 的 ::1，请用 `localhost` 而不是 `127.0.0.1` 访问。

## 使用流程

1. 填项目名 → 选择音频/视频 → 上传（后端转 16kHz 单声道；视频另存原始文件供导出剪视频）
   - 上传是**流式落盘**，几 GB 的 2 小时视频也不会把内存打满
2. 点「转写」：走**异步任务 + 进度轮询**（长素材不会把请求挂死）
   - CPU 参考速度：3 分钟素材约 53 秒；2 小时素材需数十分钟（装好 cuDNN 8 后可用 GPU）
3. 点击文字切换删除/恢复；拖拽选区后 Delete 批量删，已删选区再按 Delete 是**恢复**
4. 播放时默认跳过删除区间（听到的是剪辑结果）；用户滚动会暂停"跟随高亮"
5. 点「导出」→ 输出到 `E:\WordCut\outputs/{项目id}/`
   - `{pid}_cut.wav` 剪辑后音频
   - `{pid}_cut.srt` 重定时字幕
   - `{pid}_cut.edl.json` 编辑决策列表

> 超过 30 分钟的素材，波形自动改用 8kHz MP3 预览（2 小时约 20MB），避免浏览器解码巨型 WAV。
