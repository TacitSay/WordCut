# 启动说明

## 前置

- Python 3.10 + 依赖：fastapi uvicorn faster-whisper ctranslate2==4.4.0 numpy soundfile
- Node.js 20+
- 模型：`E:\WordCut\models\faster-whisper-small`（config.json / model.bin / tokenizer.json / vocabulary.txt）

> ⚠️ ctranslate2 必须是 **4.4.0**（4.8.3 在本机 CPU/GPU 均崩溃 0xC0000005）

## 启动后端

```powershell
cd E:\WordCut\src
python -m uvicorn api:app --host 127.0.0.1 --port 8000
```

健康检查：http://127.0.0.1:8000/api/health
接口文档：http://127.0.0.1:8000/docs

## 启动前端

```powershell
cd E:\WordCut\frontend
npm install     # 首次
npm run dev
```

访问：**http://localhost:5173**

> 注意：vite 只监听 IPv6 的 ::1，请用 `localhost` 而不是 `127.0.0.1` 访问。

## 使用流程

1. 填项目名 → 选择音频 → 上传（后端转 16kHz 单声道）
2. 点「转写」（faster-whisper 词级对齐，5 分钟音频约 105 秒 CPU）
3. 点击文字切换删除/恢复，波形区红色标注删除区间
4. 点「导出」→ 输出到 `E:\WordCut\outputs/{项目id}/`
   - `{pid}_cut.wav` 剪辑后音频
   - `{pid}_cut.srt` 重定时字幕
   - `{pid}_cut.edl.json` 编辑决策列表

## 生产构建

```powershell
cd E:\WordCut\frontend
npm run build      # 产物在 dist/
```
