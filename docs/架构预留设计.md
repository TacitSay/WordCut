## 1. Segmenter 接口（分段策略可替换）

### 定义

```python
# src/segmenter.py
class Segmenter(Protocol):
    def segment(self, tokens: list[Token]) -> list[list[Token]]:
        """把 token 序列切成段落，返回段落列表（每段是 token 列表）"""

# 内置实现
class RuleSegmenter(Segmenter):
    """规则分段：seg 变化 / 标点 / 间隔 > 阈值"""

class LLMSegmenter(Segmenter):
    """语义分段：调用本地小模型判断边界（预留，不实现）"""
```

### 扩展方式
新增分段策略 = 新增一个实现类 + 注册。**不修改** TextEditor / API / 数据模型。

### 当前默认
`RuleSegmenter(seg_change=True, punct=True, gap_threshold=0.6)`

## 2. 媒体处理：MediaProbe / MediaConverter / Splitter

### 现状
后端 `api.py` 的上传接口目前用 `soundfile` 解码，**只支持音频**，且重采样是线性插值（质量一般）。

### 目标架构

```
导入（Import）
  ├─ MediaProbe     探测容器/流（ffprobe）
  ├─ MediaConverter 统一转 16kHz 单声道 wav（ffmpeg）
  └─ StemSeparator  人声/伴奏分离（demucs，预留）
        ↓
    源音频（source_audio，只读）
        ↓
    [文本驱动剪辑 → EDL]
        ↓
导出（Export）
  ├─ AudioRender    剪辑后音频（已实现）
  ├─ VideoCut       按 EDL 切视频（预留，ffmpeg）
  └─ AVConcat       音视频合流（预留，ffmpeg）
```

### 接口定义

```python
# src/media/probe.py
def probe(path: Path) -> MediaInfo:
    """返回 {duration, streams: [{type, codec, sample_rate, channels, width, height}]}"""

# src/media/converter.py
def convert_to_wav16k(src: Path, dst: Path) -> None:
    """任意音视频 -> 16kHz 单声道 PCM16 wav（ffmpeg 子进程）"""

# src/media/separator.py
def separate_vocals(src: Path, out_dir: Path, model: str = "htdemucs") -> Stems:
    """返回 {vocals: Path, instrumental: Path}（预留，依赖 demucs）"""

# src/media/video.py
def cut_video(src: Path, deletes: list[DeleteSpan], dst: Path) -> None:
    """按 EDL 删除区间切视频（remux，不重编码优先）（预留）"""

def concat_av(video: Path, audio: Path, dst: Path) -> None:
    """视频轨 + 剪辑后音频轨 合流（预留）"""
```

### 现在的落地范围
- ✅ `probe` + `convert_to_wav16k`：**现在实现**（替换掉 soundfile 线性重采样，质量更好且支持视频）
- ⏸ `separate_vocals` / `cut_video` / `concat_av`：**只定义接口 + 抛 NotImplementedError**，作为插件挂载点

## 3. 轨道模型（视频轨先写空）

### 数据模型

```python
@dataclass
class Track:
    id: str
    kind: str          # "audio" | "video" | "subtitle" | "text"
    name: str
    source: str | None # 源文件路径
    visible: bool = True
    muted: bool = False
    locked: bool = False

@dataclass
class Timeline:
    tracks: list[Track]
    sample_rate: int
```

### 当前阶段
- 只创建 **1 条 audio 轨**（source_audio）
- **video 轨写空但不渲染**，数据结构里存在，前端预留 `VITE_ENABLE_VIDEO_TRACK` 开关

### 好处
将来加视频剪辑：数据模型已有轨道概念，无需重构 EDL（EDL 已经是独立的时间轴编辑决策）。

## 4. 命令注册表（插件入口）

```js
// frontend/src/core/commands.js
export const commands = new Map()

export function registerCommand({ id, title, menu, shortcut, handler, enabled }) {
  commands.set(id, { id, title, menu, shortcut, handler, enabled })
}
```

- 菜单栏、快捷键、右键菜单**统一从 commands 渲染**
- 插件加载时调用 `registerCommand` 即可把能力挂进所有入口

## 5. 菜单结构（L1）

```
文件(F)   编辑(E)   视图(V)   工具(T)   播放(P)   插件▾   帮助(H)
├ 导入…        ├ 删除       ├ 波形       ├ 转写       ├ 播放/暂停  ├ (插件注入)   ├ 关于
├ 导出…        ├ 恢复       ├ 分段显示   ├ 导出字幕   ├ 跳转…
├ 关闭          ├ 全选       └ 主题       └ 偏好
                └ 撤销
```

「插件▾」菜单默认只有「管理插件…」，插件注册后可注入新项。
