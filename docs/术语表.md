# 术语表（Glossary）

> 目的：锁死命名，防止 AI 生成代码时概念漂移。任何代码/文档引用这些概念时，必须用「代码标识」，禁止用「禁止别名」。

| 术语 | 定义 | 代码标识 | 禁止别名 |
|------|------|---------|---------|
| 词级单元 | 对齐后最小可剪辑单元（中文=单字，英文=词） | Token | word / segment / unit |
| 删除区间 | 一次文本删除对应的音频时间区间 | DeleteSpan | cut / trim / remove_range |
| 编辑决策列表 | 非破坏性编辑的决策集合 | EDL | edit_list / changes / ops |
| 时间映射表 | 源时间↔目标时间的分段线性映射 | TimeMap | timeline / mapping |
| 词级对齐 | 把语音 token 对齐到精确时间戳 | alignment | sync / timestamp |
| 剪辑点 | 音频被剪切的样本位置 | cut_point | cut / edge / boundary |
| 静音谷底 | 可剪区间内能量最低点 | silence_valley | valley / min_point |
| 源音频 | 导入的原始音频（只读） | source_audio | original / raw |
| 目标音频 | 剪辑后导出的成品 | output_audio | result / final |
| 播放头 | 当前试听位置 | playhead | cursor / position |
| 剪辑点精修 | 对剪辑点做声学修正（谷底吸附/过零/交叉淡化） | cut_refine | polish / fix |

## 命名规范

1. 代码标识一律英文 snake_case（如 cut_point、delete_span）
2. 前端 / 后端 / 文档统一用上表，禁止各起各名
3. 发现新概念需要命名时，先补进本表，再写代码
