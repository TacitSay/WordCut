# 不变量（Invariants）

> 目的：这些规则永远不能被破坏。任何代码改动不得违反；AI 生成代码后，必须先跑不变量测试，不过即打回。

| # | 不变量 | 理由 | 对应测试 |
|---|--------|------|---------|
| 1 | 源音频文件只读，剪辑通过 EDL 生成副本 | 非破坏性编辑的前提 | 剪辑后源文件 hash 不变 |
| 2 | 所有时间戳单位为秒（float） | 避免毫秒/秒混用 | 时间戳类型与范围校验 |
| 3 | EDL 可逆：回放结果 == 导出结果（样本级一致） | 编辑模型正确性 | 样本级 diff == 0 |
| 4 | token.id 一旦生成绝不重排 | 保证引用稳定 | 编辑后 id 不变 |
| 5 | 编辑分两类：删除（影响音频）/ 插入（仅影响字幕） | 产品边界 | 插入不改变 EDL |
| 6 | TimeMap 双向可算：源时间↔目标时间互转 | 波形/字幕/播放头一致 | 往返映射误差 == 0 |
| 7 | 任意时间戳 start < end 且 start >= 0 | 数据合法性 | 边界校验 |

## 使用规则

1. 每条不变量对应一个单元测试，放在 tests/ 目录
2. AI 生成任何代码后，先跑不变量测试，不过即打回重生成
3. 修改不变量必须先改本文件，再改代码
