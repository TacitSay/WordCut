## 视频导出的设计要点（#5）

上传视频时，除了 16kHz 单声道 WAV（用于转写/剪辑），还需**保留原始视频文件**：

```
上传 mp4
  ├─ 原始视频 -> uploads/{pid}.source.mp4   （只读，用于导出时剪视频）
  └─ 提取音频 -> uploads/{pid}.wav          （16kHz 单声道，转写与剪辑用）
```

导出视频流程：

```
1. cut_video(source.mp4, deletes, tmp.mp4)   ffmpeg 按 EDL 切视频（remux 优先）
2. av_concat(tmp.mp4, target.wav, out.mp4)  用剪辑后音频替换视频音轨
```

**关键约束**：
- 若 remux 后视频时长与目标音频不一致，以音频为准（截断 / 补静音）
- 视频源只读（不变量 1）
- 无视频源时，导出视频选项置灰

## 工程文件格式（.wcproj，方案 A）

```json
{
  "format": "wordcut-project",
  "version": "1",
  "project_id": "a1b2c3d4e5f6",
  "name": "访谈_第3集",
  "source": {
    "audio_path": "E:/WordCut/uploads/a1b2c3d4e5f6.wav",
    "audio_hash": "sha256:...",
    "original_path": "F:/树林/心理/merged_video.mp4",
    "original_kind": "video",
    "sample_rate": 16000,
    "duration": 300.0
  },
  "words": [ ... ],
  "deleted_ids": ["t00001", "t00002"],
  "in_out": null,
  "created_at": "2026-10-27T14:00:00+08:00",
  "modified_at": "2026-10-27T15:30:00+08:00"
}
```

**打开时校验**：
- `source.audio_path` 存在且 hash 匹配 → 正常打开
- 不存在 → 提示"请重新定位源文件"
- hash 不匹配 → 警告"源文件已变更"，但仍允许打开（EDL 可能失效）
